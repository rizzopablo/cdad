# RED selection — promise A

**Question:** What breaks for the user without this test?

The user cannot rely on a single interlocutor or know which role owns the next
step; a design could attribute a fictitious direct conversation to the architect
or fail to reserve independent review. This directly affects the epic's intended
workflow, rather than testing a formatting preference.

**Selection:** Promise A (PC-1 and PC-2), pending documentary behavior. The
isolated test-writer selects the smallest meaningful observable check; a
structural verifier cannot prove that instructions are understandable or that an
agent follows them. Semantic judgment and observed agent use remain independent
evidence, not substitutes for RED.
