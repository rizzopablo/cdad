+# Architecture Decision Records (ADR)
+
+The project's architectural decisions. Immutable once accepted.
+
+## When to create an ADR
+
+If within 6 months, someone (you or an agent) could ask **"why did we do X this way?"**, that decision deserves an ADR.
+
+Typical examples:
+
+- Choice of database.
+- Architecture decision (monolith vs services, layering, bounded contexts).
+- Choice of a main library when there were alternatives.
+- Patterns that are deliberately forbidden.
+
+## When NOT to create an ADR
+
+- Local implementation decisions (which algorithm to use inside a function).
+- General project conventions (they go to `systemPatterns.md`).
+- Current state or work in progress (it goes to `activeContext.md`).
+
+## Numbering and format
+
+`ADR-NNN-title-in-kebab-case.md`. Sequential numbering.
+
+Template in `<skill>/assets/adr-template/ADR.md`.
+
+## Possible states
+
+- **Proposed**: under discussion.
+- **Accepted**: approved, in force.
+- **Deprecated**: no longer applies but was not replaced.
+- **Superseded by ADR-NNN**: replaced by another ADR.
+
+Once **Accepted**, an ADR is not modified. If the decision changes, a new ADR is created that `supersede`s the previous one.

+# System Patterns
+
+Technical conventions, patterns, and structural rules of the project. This file is loaded at the start of every agent session.
+
+## Current decisions
+
+The decisions that govern this project, one row per decision. This section is the
+index of the project's ADRs: it says which ones are in force, and it is the only
+place where that is written down.
+
+The table starts **empty**: a project with no decisions yet has no rows. A row is
+added when a decision is approved; the row of a replaced decision is kept and
+marked obsolete.
+
+| File | State | Summary | Roles | Reference |
+|---|---|---|---|---|
+
+- **File** — the path of the decision's file, relative to the project root (for
+  example `docs/adr/ADR-NNN-<slug>.md`).
+- **State** — `vigente` (in force) or `obsoleto` (replaced; the row is kept, with its
+  replacement, so the history stays in the table).
+- **Summary** — one line: what the decision decides.
+- **Roles** — the roles that must consume the decision (the delegated roles and/or
+  the orchestrator).
+- **Reference** — where the rule that the decision materializes lives (it may point
+  into the installed skill tree).
+
+**Note.**
+
+- The state of a row is declared by whoever maintains the table: it is written in
+  the row itself, never re-derived from the ADR's own text.
+- The rows that are excluded are the decisions that are not in force yet (the
+  `Proposed` ones): they get a row when they are approved, and the list is updated
+  then. The excluded ones are not listed here.

+"""Notes are kept in notes.json as a JSON list; a note's id is its list index."""
+import json, os
+PATH = os.environ.get("NOTES_FILE", "notes.json")
+
+def load():
+    if not os.path.exists(PATH):
+        return []
+    with open(PATH) as f:
+        return json.load(f)
+
+def save(items):
+    with open(PATH, "w") as f:
+        json.dump(items, f)
+
+def add(text):
+    items = load()
+    items.append({"text": text})
+    save(items)
+    return len(items) - 1
+
+def delete(note_id):
+    items = load()
+    del items[note_id]  # later notes shift down by one
+    save(items)
+
+def all_notes():
+    return list(enumerate(load()))
