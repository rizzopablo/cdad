=================
Idea Log
=================

Idea Log is a minimal example module used to validate the CDAD x Odoo test
environments. It lets you capture ideas, score them, vote on them and follow
their status from draft to implemented.

**Table of contents**

.. contents::
   :local:

Usage
=====

* Create ideas with a score (1-10) and an effort level.
* Add votes from the Votes tab.
* Accept an idea with the status bar to set the accepted date.

Known issues / Roadmap
======================
